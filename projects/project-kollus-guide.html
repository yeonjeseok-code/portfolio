01

개인의 기억에 의존하던 업로드

Kollus VOD를 도입한 뒤 업로드 도구 선택부터 암호화와 채널 설정까지 확인할 요소가 많았습니다. 담당자마다 방법을 다르게 기억하면서 같은 질문과 재작업이 반복됐습니다.

직접 작업하며 헷갈리는 지점과 실패 사례를 모았습니다. 이를 바탕으로 파일 준비부터 업로드 완료 확인까지 따라갈 수 있는 가이드를 작성했습니다.

02

작업 순서와 선택 기준을 함께 정리

  1. 최종 파일 준비

    최종 편집본을 모으는 폴더 구조와 파일명 규칙을 정리했습니다. 파일명 중복 등 작업 시 주의할 제약도 함께 기록했습니다.

  2. 업로드 방법 선택

    단일 파일과 다량 파일 업로드에 맞춰 콘솔과 업로더의 사용 방법을 구분했습니다. 각 경로의 화면과 설정 위치를 안내했습니다.

  3. 암호화와 채널 설정

    암호화 여부와 카테고리 설정을 확인하는 순서를 정했습니다. 채널과 미디어키 정보도 작업 흐름에 포함했습니다.

  4. 완료 상태 확인

    파일 전송이 끝난 뒤 콘솔에서 상태를 확인하도록 체크리스트를 만들었습니다. 자주 놓치는 항목은 별도의 주의사항으로 표시했습니다.

03

담당자가 참고할 수 있는 문서로

화면별 설명과 체크리스트를 포함한 가이드를 제작해 팀과 조직에 공유했습니다. 구두로 전달하던 작업 방법을 문서에서 찾아볼 수 있도록 정리한 결과물입니다.

새 도구를 도입하는 것뿐 아니라 실제 담당자가 선택하고 확인해야 할 지점까지 문서화한 경험입니다.
