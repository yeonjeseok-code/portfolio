제작·시스템 전환과 카테고리 인수인계

새로운 포맷과 시스템이 실제 업무에 자리 잡도록 화면, 작업 순서, 접근 권한, 인수인계 기준을 정리했습니다.

01

변화의 현장에서 맡은 네 가지 일

새로운 수업 형태와 시스템이 도입될 때 실제 업무에서 막히는 부분을 확인했습니다. 각각 다른 시기에 수행한 네 가지 작업을 현업 테스트와 운영 기준 정리라는 관점으로 묶었습니다.

02

새로운 수업과 시스템을 검토하다

  1. 라이브 클래스의 표현 방식 정리 / 2022.02부터

    기존 VOD와 라이브 수업이 혼동되는 지점을 확인하고 별도 랜딩 페이지가 필요한 이유를 정리했습니다. 에디터로 페이지를 만들고 디자이너와 협업해 LIVE 배지와 커버를 제작했습니다.

  2. 세일즈포스 초기 테스트 / 2022.04

    기획자의 실제 업무 순서에 맞춰 기능을 사용해봤습니다. 필요한 필드와 불필요한 기능을 구분하고 데이터 입력과 화면 이동에서 발견한 개선 의견을 개발 및 제작팀에 전달했습니다.

03

제작 흐름과 인수인계를 정리하다

후임자가 독립적으로 수행할 수 있는 인수인계

업무를 설명하는 데서 끝내지 않고, 후임자가 판단과 실행에 필요한 정보를 찾아볼 수 있도록 오랜 기간 인수인계 문서를 준비했습니다. 문서 전달 후 퇴사한 이후에는 인수인계 관련 문의를 받지 않았습니다.

  1. 선제작 방식 전환 테스트 / 2021.12

    수요조사 후 제작하던 방식에서 먼저 제작하는 방식으로 전환할 때 작업 동선을 확인했습니다. 크리에이터의 권한 접근 문제를 발견하고 페이지 생성 흐름을 정리해 개발 요청으로 연결했습니다.

  2. 아트 카테고리 인수인계 문서 제작

    섭외와 커리큘럼 검토 기준, 이미지·키트 준비, MD 협업, 매출 이력까지 업무에 필요한 정보를 문서화했습니다.

04

작업을 통해 남긴 것

라이브 전용 페이지와 시각 요소를 만들었고 시스템 도입 과정에는 현업 피드백을 전달했습니다. 제작 전환 과정의 권한 문제를 개발 요청으로 연결했으며 인수인계에 필요한 지식은 문서로 남겼습니다.

공통된 역할은 새 방식이 실제 업무에서 어떻게 작동하는지 확인하고 다음 담당자가 참고할 수 있는 기준을 만드는 것이었습니다.
